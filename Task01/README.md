# Task01. Данные для лабораторной работы

## Структура файлов данных

### movies.csv
Информация о фильмах. Столбцы (через запятую):
- `movieId` — идентификатор фильма
- `title` — название фильма (с годом выпуска в скобках)
- `genres` — жанры фильма, перечислены через `|` (список возможных жанров — в `genres.txt`)

### ratings.csv
Оценки пользователей. Столбцы (через запятую):
- `userId` — идентификатор пользователя
- `movieId` — идентификатор фильма
- `rating` — оценка (от 0.5 до 5.0)
- `timestamp` — время выставления оценки в формате Unix-времени

### tags.csv
Теги, добавленные пользователями к фильмам. Столбцы (через запятую):
- `userId` — идентификатор пользователя
- `movieId` — идентификатор фильма
- `tag` — текст тега
- `timestamp` — время добавления тега в формате Unix-времени

### users.txt
Информация о пользователях. Столбцы разделены символом `|`:
- идентификатор пользователя
- имя пользователя
- email
- пол
- дата регистрации
- профессия (список возможных значений — в `occupation.txt`)

### genres.txt
Список возможных жанров фильмов (по одному на строку).

### occupation.txt
Список возможных профессий пользователей (по одному на строку).

## Дополнительные файлы

### ratings_count.txt
Содержит две строки: минимальный и максимальный идентификатор пользователя из `ratings.csv` с количеством строк, соответствующих каждому из них.

### sqlite.txt
Содержит установленную версию SQLite и список режимов вывода данных, доступных в утилите `sqlite3`.
